Inlanefreight Footprinting

By: Svfear

Initial Access & Scope

To begin we need to add the target IP to the inlanefreight.htb domain in the local /etc/hosts file to ensure proper resolution during the enumeration phase.

# Command used:
echo "10.129.x.x  inlanefreight.htb" | sudo tee -a /etc/hosts

WHOIS Record Enumeration

The first objective was to retrieve the IANA ID. I performed a WHOIS query against the target domain to gather registrar details.

whois inlanefreight.htb

The IANA ID was successfully identified in the registrar information block.

Fingerprinting Web Technologies

I utilized whatweb to identify the web server and backend technologies. The scan revealed the target is running an nginx web server.

Vhost Fuzzing & Admin Discovery

While robots.txt on the main domain was limited, I moved to Virtual Host (Vhost) brute-forcing. This led to the discovery of a non-standard subdomain: web1337.inlanefreight.htb.

Checking the robots.txt on this new subdomain revealed a hidden directory: /admin_h1dd3n/.

Successfully retrieved the first API key from the hidden directory.

Advanced Crawling with ReconSpider

The final task required finding a specific email address. My initial attempt with ReconSpider.py on the discovered subdomain yielded no results.

python3 ReconSpider.py http://web1337.inlanefreight.htb:30907

Recognizing the need for deeper enumeration, I performed another round of fuzzing which uncovered dev.web1337.inlanefreight.htb. Running the spider on this development subdomain was successful.

Conclusion: Final email and administrative keys were extracted via deep subdomain fuzzing and automated crawling.
